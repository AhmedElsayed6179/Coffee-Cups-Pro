# Coffee Cups ☕
> **Premium Coffee E-commerce & Catalog Platform**

**Coffee Cups** is a sleek, full-stack web application designed for coffee shops and retail brands. It showcases a premium selection of coffee products with a focus on high-quality visuals, interactive user experience, and a robust management backend.

---

## 🚀 Key Features
* **Product Catalog:** Dynamic display of coffee products fetched from a **MySQL** database.
* **Smart Filtering:** Easily browse through categories and product types.
* **Interactive Cart:** A smooth, JavaScript-powered shopping experience.
* **Admin Control Panel:** Manage inventory, update prices, and add new arrivals via a secure **PHP** backend.
* **Responsive Layout:** A mobile-first design that looks stunning on every device.
* **Modern UI:** Clean aesthetic with smooth transitions and hover effects.

---

## 🛠 Tech Stack
* **Frontend:** HTML5, CSS3 (Modern layouts), JavaScript (Vanilla).
* **Backend:** PHP (Server-side processing).
* **Database:** MySQL (Relational storage).
* **Hosting:** Live version available at [coffee-cups.page.gd](https://coffee-cups.page.gd/).

---

## ⚙️ Local Setup
1.  **Clone the project:**
    ```bash
    git clone [https://github.com/your-username/coffee-cups.git](https://github.com/your-username/coffee-cups.git)
    ```
2.  **Server Hosting:**
    * Place the folder in your `htdocs` or `www` directory.
3.  **Database Migration:**
    * Create a database in **phpMyAdmin**.
    * Import the provided SQL file.
4.  **Configuration:**
    * Configure your database credentials in the connection file (e.g., `db_connect.php`).
